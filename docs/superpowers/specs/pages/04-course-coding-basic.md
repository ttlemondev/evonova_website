## 二、课程内容

### 2.1 课程概述

**核心特点:**
- 零基础门槛:面向所有人,极低入门门槛
- 实战驱动交付:通过 1 天时间,带领学员亲手用 Claude Code 从零构建一个包含前端、后端、数据库的外卖点餐系统(MVP 级别)
- 高频互动小循环:采用"理论 → 实操 → 答疑"的螺旋式开展模式,确保 70% 以上的当场掌握率

### 2.2 课程大纲

**Ch1 开场与激励**
- 了解学员背景与技术栈情况
- 通过演示让学员直观体验 AI 编程的真实生产力
- 涵盖知识点:编程生成动画和 PPT 展示、每日 GitHub 提交记录与 Token 消耗量展示、Agentic 编程理念认知

**Ch2 安装与环境**
- 完成 Claude Code 工具的安装与认证配置
- 由 AI 自主选择技术栈并初始化全栈外卖项目框架
- 涵盖知识点:原生安装器使用、Anthropic 账号或 API Key 认证配置、VS Code/IDE 集成、工具的权限确认机制

**Ch3 基础操作**
- 学习工具的基础命令与交互方式
- 通过实战完成包含前端与后端的"菜单浏览页面"构建
- 涵盖知识点:快捷键与常用斜杠命令速查、基础提示技巧三原则、@文件引用、处理截图和视觉内容

**Ch4 项目配置**
- 学习利用规范约束 AI 行为,统一团队的业务规则与代码风格
- 在规则指导下完成购物车功能
- 涵盖知识点:CLAUDE.md 配置文件与 /init 命令、五层配置体系、四种权限模式的适用场景与切换

**Ch5 上下文与模型**
- 学习 AI 工具的"内存"管理机制以及模型经济学
- 利用高阶模式规划并实现复杂的下单及订单管理系统
- 涵盖知识点:200K 上下文窗口管理与 /compact 清理、会话恢复与并行处理、模型选择策略、/effort 思考深度调节、Plan 模式使用技巧

**Ch6 日常工作流初体验**
- 在完整的全栈应用上体验真实开发中的调试、重构与测试工作流
- 实现订单状态流转与折扣计算功能
- 涵盖知识点:自然语言 Debug 定位与修复问题、代码结构重构、Checkpointing 一键回滚、对话式 Git 操作、TDD 极简版演示

**Ch7 布置作业**
- 布置带有业务痛点的实战开发任务
- 要求在现有的全栈外卖系统上独立扩展功能模块
- 涵盖知识点:综合运用所学知识独立完成"统计页面"的前后端开发闭环

### 2.3 适合人群

- 所有人,无需任何基础
- 对 AI 编程感兴趣的初学者
- 希望快速了解 Claude Code 能力的开发者

### 2.4 课程目标

- 了解 Claude Code 的强大能力
- 掌握最基础的命令与用法
- 从 0 到 1 产出一个完整的 MVP 级别应用
- 建立对 AI 编程的信心和兴趣

### 2.5 课程特色

- 完整性:包含前端与后端闭环,实操课后必定产出一个完整的 MVP 级别应用
- 聚焦 80% 的高频主干知识:抛弃枯燥的理论堆砌,专注于覆盖 80% 通用场景的"主干知识"
- "理论-实操-答疑"的小循环设计:螺旋式开展课程,保证极高的当场转化率(目标 70% 掌握)
