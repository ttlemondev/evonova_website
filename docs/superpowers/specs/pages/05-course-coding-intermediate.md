## 二、课程内容

### 2.1 课程概述

**准入门槛:**
- 面向具有一定基础的学员(建议具备 2-8 周 Claude Code 实际使用经验)

**核心定位:**
- 从"个人单兵作战"升级为"团队协同规范"
- 认知并掌握完整的 Claude Code 扩展生态
- 搭建符合企业自身的自动化开发工作流

**实战驱动:**
- 以从零搭建一个完整的"任务管理系统 (task-manager)"为主线贯穿全天
- 通过为该系统逐步添加任务增删改查、评论协作、看板视图、外部数据同步等真实用户故事
- 让学员在真实业务场景中消化所有高阶自动化工具

### 2.2 课程大纲

**模块一:SOP 标准化规范 (Skill)**
- 解决团队成员"提示词质量参差不齐"的问题
- 将优秀的操作流程固化为可重复调用的标准 SOP
- 涵盖知识点:自定义 Skill 编写、动态上下文注入、带约束的团队统一指令

**模块二:AI 代理与自动化检查 (Agent & Hook)**
- 让 AI 分身处理安全审查
- 在代码修改、执行高危命令前后触发自动化拦截与代码测试
- 涵盖知识点:Sub Agent 专项审查代理搭建、三种自动化钩子、危险命令自动拦截

**模块三:配置体系与插件分发 (Plugin)**
- 梳理个人、项目与全局的三层配置体系
- 将定制好的团队工具链打包为插件,实现新员工"一键入职"
- 涵盖知识点:三层 Settings 优先级覆盖、Plugin 目录结构与 plugin.json、团队私有工具包的 Git 分发与复用

**模块四:规范驱动开发 (Spec-Kit)**
- 抛弃随意的口头提示词
- 学习用结构化的 PRD 规范文档驱动 AI 生成高质量代码
- 涵盖知识点:Spec-Kit 五步法、BMAD-Method 多角色专家开发框架认知

**模块五:打破边界的外部集成 (MCP Server)**
- 为 AI 接入"USB 接口"
- 让 AI 突破本地限制,直接读取 GitHub Issue、查询数据库并自动提交 PR
- 涵盖知识点:MCP 原理与三种作用域、集成 GitHub MCP、集成 SQLite MCP

**模块六:CI/CD 流水线与前沿探索**
- 彻底剥离人工点击,将 AI 代码审查接入 Git 流水线
- 拓展学习多智能体并行协作的未来形态
- 涵盖知识点:Headless 无头模式脚本化调用、集成 GitHub Actions / GitLab CI 自动审查 PR、Agent Teams 并发协作

### 2.3 适合人群

- 有 2-8 周实际使用经验的开发者
- 希望将 AI 编程应用在实际项目中的团队
- 需要建立团队协作规范的技术负责人

### 2.4 课程目标

- 初步认知完整生态(Plugin、MCP、Agent 等)
- 借助已有"轮子"将其应用在实际业务项目中
- 实现生产效率的翻倍(2X 提效)
- 建立团队级的自动化工作流

### 2.5 课程特色

- 完整生态覆盖:从 Skill 到 MCP,从 Plugin 到 CI/CD
- 实战项目驱动:以任务管理系统为主线,真实业务场景
- 团队协作导向:不只是个人能力,更是团队规范
