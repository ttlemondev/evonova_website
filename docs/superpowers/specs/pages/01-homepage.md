# 首页详细设计

**页面路径:** `/`  
**页面类型:** 单页滚动式  
**设计日期:** 2026-05-17

---

## 一、页面概述

### 1.1 页面目标

首页是用户了解熵序之间的第一入口,需要在短时间内:
1. 传达品牌核心价值:"构建 AI 原生组织,释放百倍生产力"
2. 展示双产品线:AI 原生组织 + AI 编程培训
3. 说明服务模式:系统化培训 + AI 编程辅导
4. 引导用户了解课程详情或预约咨询

### 1.2 页面结构

首页采用单页滚动式设计,包含 8 个主要区块:

1. Hero 区 (首屏)
2. 问题区 ("AI 时代,组织面临的挑战")
3. 方案区 ("我们的解决方案" - 双产品线)
4. 服务模式区 ("培训 + 辅导,保下限拔上限")
5. 课程体系区 ("完整的学习路径")
6. 采购建议区 ("推荐套餐")
7. 为什么选择我们区 (可选)
8. 联系我们区 (页脚)
