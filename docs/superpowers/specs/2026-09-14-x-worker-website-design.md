# X Worker 网站整合设计

## 目标

将 X Worker 作为 TOPFX “AI 原生组织转型”的核心落地平台加入网站，使访客理解 TOPFX 不仅提供培训与陪跑，也能通过数字员工团队将企业知识、技能和流程沉淀为持续运行的业务能力。

## 信息架构

- 首页新增独立 X Worker block，位于解决方案之后、服务能力之前。
- 新增 `/[locale]/x-worker` 产品详情页。
- 服务页从“培训 + 辅导”扩展为“场景诊断 + 平台实施 + 培训运营”。
- 关于页将“其他产品”调整为“产品与能力”，突出 X Worker，保留 NexRouter 为关联基础设施产品。
- 联系表单新增咨询类型和业务场景字段。
- 导航新增 X Worker、服务方案，Footer 快速链接同步更新，但不恢复 NexRouter Footer 链接。

## 首页 X Worker Block

首页 block 只承担快速理解和导流，并以产品 mockup 为主要信息载体：

1. 定位：企业 AI 工作平台与数字员工团队。
2. 产品形态：用多数字员工协作 mockup 展示 Leader 拆解任务、Member 并行执行、共享产出和人工审批。
3. 文案范围：一个短标题、一句说明和一个详情页入口，不在首页重复展开功能清单。
4. 转化：进入 X Worker 详情页。

## X Worker 产品页

产品页首屏后直接展示产品 mockup，再依次包含企业痛点、工作方式、核心能力、典型场景、部署安全、实施路径、效果指标和咨询入口。页面沿用现有网站的白底、Card 和 ColorBlock 视觉体系，不使用独立的深色科技风页面语言。内容不得宣称未经验证的客户案例、效率倍数或固定节省数字。

## 内容边界

- X Worker 是面向企业客户的 AI 工作平台，不描述为 NexRouter 的内部模块。
- TOPFX 负责场景诊断、流程设计、培训、实施和持续运营。
- NexRouter 只作为可选的模型接入与基础设施支持，不重新出现在 Footer 的独立产品栏目。
- 中英文页面保持同一结构和语义。

## 验收

- 中文和英文路由均可访问。
- 首页、导航、Footer、服务、关于、联系页面均能正确引导至 X Worker。
- 联系表单可选择咨询类型并填写业务场景。
- ESLint 和 Next.js 生产构建通过。
