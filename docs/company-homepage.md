# Company homepage redesign

The active homepage is `/en`. The company is presented as TOPFX PTE. LTD., an AI company building consumer apps. The visual direction uses off-white, cobalt, editorial typography, an original parametric sculpture, real product imagery, and a dark engineering section.

## Run locally

```powershell
cd C:\LocalProject\ai-train-website-company
npm ci
npm run dev -- --hostname 127.0.0.1 --port 3002
```

Open http://127.0.0.1:3002/en. The original checkout and its server on port 3001 are independent.

```powershell
npm run lint
npm run build
node scripts/verify-company-home.mjs
```

The smoke script accepts another server origin as its first argument. A production server can be started with `npm run start -- --hostname 127.0.0.1 --port 3003` after building.

## Content and provenance

Product copy is paraphrased from the official listings, checked on September 22, 2026:

- [PokeVid on Google Play](https://play.google.com/store/apps/details?id=com.poke.ai.video.gen&hl=en): text-to-video, photo animation, image creation and creative templates.
- [iPulse on the App Store](https://apps.apple.com/tw/app/ipulse-heart-rate/id6755516849?l=en-GB): camera-based heart-rate measurement, habits and emotional wellbeing. The site makes no AI-diagnosis or clinical-accuracy claims.
- [BreezeBlue](https://breezeblue.ai/) informed the restrained blue palette, generous spacing and clear hierarchy. No source code, copy or imagery was taken from that site.

Product icons and screenshots are from the apps' own public store listings. Exact asset URLs are recorded in `public/images/products/sources.json`. The English store screenshots have been visually checked. No download counts, performance claims, client logos, testimonials, or ratings have been invented.

The decorative vector form is original, generated by `node scripts/generate-brand-form.mjs`. Desktop and mobile use separate compositions selected by a native `picture` element. No animation or graphics library is required.

## Routes and contacts

- `/` and `/zh` lead to the English homepage, independent of browser language.
- Existing English, Chinese and unprefixed about/contact/services/course/X Worker URLs redirect to the corresponding company, contact, approach or products section. Query strings are retained. Legacy source files remain for reference; these legacy pages are not part of the new navigation.
- Published `#hero` and `#solutions` bookmarks retain native HTML targets: the hero or engineering section. These aliases also work without JavaScript and after the Chinese homepage redirects to English. The retired `#courses` anchor is intentionally absent: courses are not associated with the engineering section.
- The unchanged email is `contact@topfx.top`; the unchanged displayed telephone is `+65 8287709`. GitHub, Twitter and LinkedIn links are removed at the owner's request.
- Contact actions use real email/telephone links. There is no simulated form submission.
- The root layout is the only owner of `html` and `body`, correcting the former nested-document hydration warning.

## Browser acceptance

Check desktop and mobile layouts, product anchor navigation, both static engineering articles (visible without switching), mobile menu open/close/Escape behavior, contact anchors, language, image loading, console errors, and horizontal overflow. External store links open in a new tab and include the same app IDs supplied in the brief.

## Editorial refinement

The homepage has no introductory eyebrow, decorative section numbers or section-name labels above its headings. The “Thoughtfully engineered” caption is also removed. The engineering section is a static editorial pair, connecting generative-media work to PokeVid and mobile-device capabilities to iPulse. All content is visible without tabs, carousels or diagram interaction. Social links were present in the original footer but have been removed at the owner's explicit request. The original email and telephone remain.

## Motion

Native smooth scrolling applies to section links and Back to top. Below-the-fold headings, product cards and editorial content rise by 20px and fade in once over 700ms, with a 90ms offset for the second column. Existing product-image hover movement is retained, accompanied by subtle link-arrow motion. No animation library is needed. Content stays visible without JavaScript; above-the-fold content is never hidden during hydration. Keyboard focus cancels an active reveal. Reduced-motion preferences disable reveals, smooth scrolling and hover displacement, including when the preference changes during a visit.
