# 三门课程的定位

1. 递进关系：这三门课程是递进关系。
    1. **初级课程：基础/入门**。目标是让初级学员了解到Claude Code的强大，用Claude Code能开发一个简单的，MVP级别的应用。学习内容是Claude Code的一些最基础的领命或者用法。
    2. **中级课程：扩展/实战**。是顺延第一门课的增强。目标是让学员能学习到Claude Code的高阶命令、以及扩展插件，初步认知 Claude Code 的完整生态。利用这些生态插件/扩展（借助“已有轮子”），大幅提高开发效率。关键概念：Plugin、MCP、Skill、Command、Agent、Speckit/BMAD。
    3. **高级课程：规模化/生产力**。高级课程目标是让学员充分利用Claude Code的全部实力，搭建符合企业自身需要的开发工作流。通过一些实战案例，让学员掌握使用 Claude Code 开发大型的、生产级项目的系统性方法，**大幅度（X10）**的提高开发效率。关键概念：安全、质量、团队协作、重构、部署、极致人效。这门课的内容通常在公开资料上是学不到的，或者说很难把它们串联起来。这门课需要授课人（或者课程开发人员）对Claude Code编程有着非常深入的理解，有非常丰富的开发实践经验。这些经验是非常宝贵的财富，是可以卖出10倍甚至100倍溢价的。我们对这门课的定位也很高，是“私董会”级别的，一般人也不让报名。
    4. 这三门课从多个角度都是递进关系：
        1. 学员的获得价值。
            1. 初级课程，了解基本命令，了解 CC 的强大，从0到1生成MVP级别应用。
            2. 中级课程，应用在实际项目中，提高生产效率（2X）。
            3. 高级课程，生产级别/大型项目/遗留项目，大幅提高生产效率（10X）。
        2. 信息的获取难度/稀缺性。
            1. 初级课程，在Claude Code官网上就能看到的知识；
            2. 中级课程，需要自己从多个GitHub资源库，或者优秀的博客/视频中学到的知识；
            3. 高级课程，公开资料很难获取到的知识，都是独家的、私享的、高阶的、实战经验。
        3. 学员的学习曲线。
            1. 初级课程，可以面向任何人的，无须任何基础。
            2. 中级课程，需要学员实际用 Claude Code 开发2~8周时间（取决于学员的编程基础和学习热情）。
            3. 高级课程，需要学员实际用 Claude Code 开发4~16周时间（取决于学员的编程基础和学习热情）。
2. 初级课程和中级课程的通用要求：
    1. 完整性。要有前端和后端，课程结束之后能产出一个完整的闭环的MVP级别的应用。
    2. 激励性。要让学员快速拿到一个可操作的 APP 作为成果，进而对Claude Code产生兴趣。不要引入太多的新概念，进而让初级学员产生畏惧。
    3. 吸引力。课程的开展要从实际操作开始，从可体验的效果开始，每一个小节都要遵守这个原则。而不要先从概念开始，因为讲概念是枯燥的，容易让人失去兴趣。
    4. 抓住主干。标准课程只 cover 80% 场景下能用的到的知识（即主干知识），剩下 20% 的知识（即细枝末节知识）交给学员在项目中探索或者课后答疑。否则学员容易在上课时丢失“主线”，进而“迷路”。
3. 初级课程的要求：
    1. 零基础。主要面向的学员是那些对AI编程几乎没有任何概念的人，我们要能考虑他们的认知层次来开展这个课程。
